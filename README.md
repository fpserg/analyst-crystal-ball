# 🔮 Хрустальный шар аналитика™

Аналитический AI-шар, который выдаёт случайные рекомендации по акциям MOEX, когда его трёшь или трясёшь.
Пародия на вебинары «вайб-кодинг в финансах». Один файл, ноль зависимостей.

**Не является инвестиционной рекомендацией, советом и вообще шаром.**

## Что умеет

- Потереть шар пальцем (или мышью) или встряхнуть телефон (`DeviceMotionEvent`)
- Сила встряхивания / скорость натирания = «убеждённость»: от `HOLD (чувствуется правильно)` до `ВСЁ В ОДНУ БУМАГУ, ПЛЕЧО 5x (не рекомендуется)`
- Случайный тикер MOEX, целевая цена с ложной точностью, «уверенность модели» всегда 90%+
- Тезис из шаблонов на баззвордах («вайб-DCF», «агентный пайплайн», «токенизированный сентимент»)
- **Режим вебинара**: тот же шар, но говорит языком лайф-коуча
- Фейковый hit rate 100%; долгий тап по нему показывает честный: «монетка»
- Paywall «Premium Orb Mastermind» за ₽49 900 с таймером
- Кнопка «Поделиться»: рисует картинку-карточку для рабочего чата

## Запуск

Откройте `index.html` в браузере. Для встряхивания на iPhone нужен HTTPS (GitHub Pages подойдёт) и разрешение на датчики движения.

Публикация через GitHub Pages: Settings → Pages → Deploy from branch → `main` / root.
